How to Use & Guide

How to Open

  1. Direct Slug: Type Loading... on ...

  3. Hub Search: Search on the root hub path (/).

How to Use

  • Enter Short URL: Paste any shortened link (e.g. bit.ly, t.co, tinyurl) into the input box.
  • Click Trace: Press Trace Path or hit Enter.
  • Inspect Pathways: View total redirect hops, status codes, and final landing URL node graph.
  • Recall Recent: Click any history item to instantly re-analyze it.

USP (Why It's Different)

  • Visual Node Graph: Clear visual diagram of every intermediate hop and status code.
  • Link Safety Shield: Inspect shortened links safely before visiting unknown destinations.
  • Persistent Memory: Recent trace histories are automatically stored locally across sessions.
