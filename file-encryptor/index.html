How to Use & Guide

How to Open

  1. Direct Slug: Type Loading... on ...
  2. Tool ID: Type Loading... on ...
  3. Hub Search: Search on the root hub path (/).

How to Use

  • To Encrypt: Choose any file, set a password, and click Encrypt & Download to generate a .mjcrypt file.
  • To Decrypt: Switch to Decrypt tab, upload the .mjcrypt file, type the password, and click Decrypt & Restore File.
  • Zero Knowledge: All crypto runs inside your web browser. No files leave your device.

USP (Why It's Different)

  • AES-256-GCM + PBKDF2: Military-grade authenticated encryption standard.
  • Smart Hybrid Download: Standard downloads for files ≤1GB, and disk streaming for >1GB files.
  • Tamper Proof: Encrypted files cannot be modified or unlocked without the exact password.
