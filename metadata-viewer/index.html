  • Save Results: Use Copy JSON or Export JSON to keep the extracted data.

AI Content Detection

  • C2PA Content Credentials: The open industry standard (used by Adobe Firefly, OpenAI, Google, Microsoft, Leica and more) for disclosing how a file was created or edited — including generative-AI origin. This tool reads that manifest directly, client-side.
  • About SynthID: Google's SynthID watermark can only be verified through Google's own proprietary detector — there's no public API for it, so no browser tool (including this one) can genuinely check for it. Be cautious of any tool that claims otherwise.
  • No Manifest ≠ Human-Made: Absence of C2PA data only means nothing was disclosed — it isn't proof the file is authentic.

USP (Why It's Different)

  • Signature Verification: Detects the real file type from its byte signature, not just the declared extension.
  • Genuinely Deep: Camera EXIF, GPS, PDF permissions/attachments, precise audio/video technicals & C2PA — all in one inspector.
