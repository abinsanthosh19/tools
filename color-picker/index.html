How to Use & Guide

How to Open

  1. Direct Slug: Type Loading... on ...
  2. Tool ID: Type Loading... on ...
  3. Hub Search: Search on the root hub path (/).

How to Use

  • Manual Pick: Click the big swatch for the native picker, or drag the R/G/B sliders.
  • Type Values: Edit the HEX field directly and press Enter.
  • From Image: Upload a photo, then click any pixel to sample its exact color.
  • Screen Pick: Use Pick From Screen to sample any pixel on your display (supported browsers).

USP (Why It's Different)

  • Image Sampling: Pull exact colors from any uploaded photo, no extra software needed.
  • Pick Color From Screen: Sample any pixel on your entire display.
  • Persistent Palette: Saved colors remain stored in local storage across browser refreshes.
