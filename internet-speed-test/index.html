How to Use & Guide

How to Open

  1. Direct Slug: Type Loading... on ...
  2. Tool ID: Type Loading... on ...
  3. Hub Search: Search on the root hub path (/).

How to Use

  • Start: Click Start Speed Test to begin the connection test.
  • Latency: Several small requests are measured to calculate ping and jitter.
  • Speed: The browser downloads and uploads test data to estimate throughput.
  • History: Completed results are stored locally in your browser.

USP (Why It's Different)

  • Client-Side: No application server is required for the UI itself.
  • Detailed Metrics: Reports ping, jitter, packet loss, download, and upload.
  • Configurable: Test endpoints can be changed without modifying the test logic.
  • Dual Theme: Matches the dark/light glassmorphism design of the tool collection.
