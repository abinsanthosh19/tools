How to Use & Guide

How to Open

  1. Direct Slug: Type Loading... on ...
  2. Tool ID: Type Loading... on ...
  3. Hub Search: Search on the root hub path (/).

How to Use

  • Click the keyboard capture area to focus it.
  • Press any key or key combination to inspect its event data.
  • Review key, code, location, modifiers, and repeat state.
  • Use the event log to review recently pressed keys.

USP (Why It's Different)

  • Live identity: Shows the browser's actual keyboard event properties instantly.
  • Modifier aware: Detects Shift, Ctrl, Alt, and Meta combinations.
  • Developer friendly: Useful for keyboard shortcuts, JavaScript events, debugging, and accessibility testing.
