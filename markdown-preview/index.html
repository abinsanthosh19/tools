How to Use & Guide

How to Use

  • Type or Upload: Write directly in the editor, or upload a .md file.
  • Watch It Render: The preview updates live as you type — no button needed.
  • Export: Copy the rendered HTML, or download it as a standalone .html or the raw .md.

USP (Why It's Different)

  • GitHub-Flavored: Tables, task lists, and strikethrough render exactly like on GitHub.
  • Highlighted Code: Fenced code blocks get real syntax highlighting, not plain text.
  • Sanitized & Safe: Rendered HTML is cleaned before display, so pasted content can't run scripts.
